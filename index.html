MÓDULO 01 · HTML5

La estructura de una página web

HTML describe qué elementos existen y cómo se organiza el contenido. CSS se encargará después de su apariencia.

💡 Explora sin miedo: todos los temas están disponibles desde el inicio. Lee, prueba los ejemplos, modifica el código y usa los quizzes para comprobar si realmente lo entendiste.
IDEA CLAVE

HTML es la estructura, no la decoración.

Piensa en una casa: HTML define habitaciones, puertas y espacios; CSS define colores, materiales y distribución visual.

⌂
Ruta paso a pasoPaso 1 de 7

Comienza por entender cómo se construye el documento HTML, desde doctype hasta body.

01 · DOCUMENTO

La estructura mínima

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Mi página</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  Contenido visible
</body>
</html>

DOCTYPE indica al navegador que trabajaremos con HTML5. head contiene metadatos, la hoja de estilos y el título. body contiene todo lo que el usuario ve.

02 · META

Metadatos importantes

Los metadatos no se muestran como texto, pero son clave para el navegador y para dispositivos móviles.

  • charset: codificación de caracteres.
  • viewport: hace que la página sea responsive.
  • link rel="stylesheet": conecta el CSS externo.
03 · CONTENIDO

¿Qué va en head y qué va en body?

HEAD metadatos, estilos, título
BODY texto, imágenes, secciones

Piensa si el elemento es visible o si sirve para configurar la página.

Interactivo: elige una etiqueta HTML

header

<header>
  <h1>Mi título</h1>
</header>

El elemento header contiene el encabezado de una sección o página y es uno de los bloques principales del documento.

🧠 Regla rápida: si el usuario lo ve en la página, normalmente estará relacionado con body. Si es información para el navegador, normalmente estará en head.
HEADER marca · título
NAV navegación
SECTION bloque temático
ARTICLE contenido independiente
FOOTER información final

¿Por qué semántica?

Las etiquetas semánticas describen el propósito del contenido. Mejoran la organización del código, accesibilidad y comprensión del documento.

  • header → encabezado.
  • nav → navegación.
  • main → contenido principal.
  • section → sección temática.
  • article → contenido independiente.
  • footer → pie de página.
  • aside → contenido secundario.
  • figure + figcaption → imágenes con leyenda.

Ejemplo real

<body>
  <header><h1>Mi tienda</h1></header>
  <nav><a href="#">Inicio</a></nav>
  <main>
    <section>
      <article><h2>Producto</h2><p>Descripción</p></article>
    </section>
  </main>
  <footer>Contacto</footer>
</body>

La semántica facilita que el navegador, las personas y los motores de búsqueda entiendan tu página.

APLICACIÓN REAL · CONTENIDO

¿Para qué sirven los textos y las listas en una página real?

📰 Encabezados

h1, h2 y h3 organizan una noticia, una tienda o una guía. Por ejemplo: Tienda → Categoría → Producto.

🛒 Listas

ul sirve cuando el orden no importa, como las características de un celular. ol sirve cuando el orden sí importa, como los pasos para comprar.

✍️ Formato

strong destaca información importante; em marca énfasis. No los uses solo para hacer letras grandes: para eso está CSS.

🔗 Enlaces

a conecta al usuario con otra página, un documento, una sección o una acción. Es fundamental en menús y botones de navegación.

Etiquetas de formato que debes reconocer

<strong>Importancia <em>Énfasis <mark>Resaltado <small>Nota secundaria <del>Texto eliminado <ins>Texto agregado <sub>H2O <sup>x2 <code>display:flex

Idea clave: estas etiquetas aportan significado al contenido. El tamaño, color, espacio y apariencia deben controlarse principalmente con CSS.

Tipos de listas y su uso real

ul

Cuando el orden no importa: ingredientes, características, menú de navegación.

ol

Cuando el orden importa: instrucciones, pasos de registro, ranking.

dl

Para términos y sus descripciones: glosarios, preguntas frecuentes o fichas técnicas.

Contenido textual

Los encabezados van de h1 a h6. Usa h1 para el título principal y organiza los niveles de manera lógica.

h1 · Título principal

h2 · Sección

h3 · Subtema

p · Párrafo de contenido.

Listas, enlaces y énfasis

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<a href="https://ejemplo.com">Visitar sitio</a>
<p>Este texto es <strong>importante</strong> y este es <em>énfasis</em>.</p>

ul crea listas sin orden; ol crea listas numeradas. Usa strong para importancia y em para énfasis.

💡 Consejo: evita usar encabezados sólo por estilo. Usa CSS para cambiar el tamaño visual y deja que el HTML exprese la jerarquía del contenido.

Imágenes

<img src="tenis.jpg"
     alt="Tenis deportivos"
     width="600"
     height="400">

alt describe la imagen cuando no puede visualizarse y ayuda a la accesibilidad. Usar width/height mejora el rendimiento.

Video, audio e iframe

<video controls width="100%">
  <source src="video.mp4" type="video/mp4">
</video>
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>
<iframe src="https://ejemplo.com" title="Contenido externo"></iframe>

Usa multimedia de forma responsable y respeta derechos de autor. Añade atributos como title y controls para mejorar la experiencia.

Accesibilidad básica

Una página accesible permite que más personas la usen, incluyendo quienes usan lectores de pantalla o navegadores con teclado.

  • alt en imágenes.
  • label en formularios.
  • title en iframes.
  • Texto claro en botones y enlaces.

Buenas prácticas

<label for="email">Correo</label>
<input id="email" type="email">
<button type="submit">Enviar

Relaciona siempre el label con el campo usando for y id. Así las personas que usan teclado o lector de pantalla entienden mejor el formulario.

♿ Consejo: etiqueta siempre los controles y evita enlaces con texto genérico como “haz clic aquí”. Usa texto descriptivo.

Formularios

<form>
  <label for="nombre">Nombre</label>
  <input id="nombre" type="text" placeholder="Escribe tu nombre">
  <label for="mensaje">Mensaje</label>
  <textarea id="mensaje" placeholder="Tu mensaje aquí"></textarea>
  <button type="submit">Enviar</button>
</form>

label identifica el campo; input recibe datos; button permite una acción. Otros elementos: select, option, textarea.

Tablas

<table>
  <thead>
    <tr><th>Producto</th><th>Precio</th></tr>
  </thead>
  <tbody>
    <tr><td>Tenis</td><td>$120</td></tr>
  </tbody>
</table>

th representa encabezados; td celdas. colspan y rowspan permiten combinar celdas.

Escribir el contenido

Dentro de body, escribe una estructura semántica. No memorices: piensa qué función cumple cada zona.

Crear style.css

1. Crea otro archivo llamado style.css.
2. Escribe una regla sencilla.
3. Guarda con Ctrl + S.

body {
  font-family: Arial, sans-serif;
  margin: 0;
  background: #f4f6fb;
}

Conectar HTML + CSS

Regresa a index.html. Dentro de head agrega:

<link rel="stylesheet" href="style.css">
💡 Si el nombre del archivo no coincide, el CSS no se aplicará.

Probar en el navegador

Guarda ambos archivos. Abre index.html en el navegador o usa Live Server si está instalado.

Margin vs. padding

margin crea espacio fuera de la caja. padding crea espacio entre el contenido y el borde.

#171b2e
#635bff
#20b6c7

Buenas decisiones visuales

  • Usa una jerarquía clara.
  • No uses demasiados colores.
  • Cuida el contraste y la legibilidad.
  • Usa espacios para evitar una interfaz saturada.
  • Piensa en la repetición de estilos para que tu sitio se vea cohesivo.

Diseño responsive

Una página moderna funciona bien en escritorio, tablet y celular. Usa reglas que cambien según el ancho de pantalla.

@media (max-width: 768px) {
  .cards {
    flex-direction: column;
  }
}

Esta regla hace que las tarjetas pasen de fila a columna cuando la pantalla es más angosta.

Flexbox y responsive

Flexbox ayuda a crear diseños que se ajustan. En móviles, combina flex-wrap con min-width para que las tarjetas no se reduzcan demasiado.

📱 Regla útil: piensa primero en el móvil y luego añade mejoras para pantallas más amplias.

⭐ MÓDULO 03 · FLEXBOX

Flexbox = tu superpoder

Aprende haciendo: escribe CSS, ejecútalo, rompe el diseño, corrígelo y descubre por qué funciona.

CONTENEDOR→EJES→ESPACIADO→RESPONSIVE
FLEX
⚡
01

La idea que debes dominar

Flexbox organiza elementos dentro de un contenedor y trabaja con dos ejes.

📦

Contenedor

El elemento que recibe display: flex. Sus hijos directos entran al sistema Flexbox.

.menu { display: flex; }
👶

Hijos

Son los elementos directamente dentro del contenedor. Sus posiciones pueden cambiar sin usar position.

<nav>
  <a>Inicio</a>
  <a>Cursos</a>
</nav>
↔️

Eje principal

flex-direction decide si el eje principal es horizontal (row) o vertical (column).

↕️

Eje transversal

Es perpendicular al principal. align-items trabaja principalmente sobre este eje.

💡 Regla mental: primero decide la dirección → después distribuye con justify-content → finalmente alinea con align-items.
02

Propiedades, una por una

No las memorices: cambia valores y observa qué propiedad controla cada cosa.

display: flexCONTENEDOR

Activa Flexbox

Convierte el elemento en contenedor flexible.

.contenedor {
  display: flex;
}
flex-directionCONTENEDOR

Define la dirección

row, row-reverse, column, column-reverse.

flex-direction: column;
justify-contentEJE PRINCIPAL

Distribuye

start · center · end · space-between · space-around · space-evenly.

justify-content: space-between;
align-itemsEJE TRANSVERSAL

Alinea los hijos

stretch · start · center · end. Muy usado para centrar contenido.

align-items: center;
flex-wrapCONTENEDOR

Permite varias líneas

nowrap mantiene una línea; wrap permite nuevas filas.

flex-wrap: wrap;
align-contentVARIAS FILAS

Alinea las líneas

Solo se nota cuando hay varias líneas con flex-wrap.

align-content: center;
gapCONTENEDOR

Separa elementos

Controla el espacio entre hijos. También existen row-gap y column-gap.

gap: 20px;
flex-flowATAJO

Dirección + wrap

Atajo para flex-direction y flex-wrap.

flex-flow: row wrap;
orderHIJO

Cambia el orden

Modifica el orden visual de un hijo.

.destacado { order: -1; }
flex-growHIJO

Puede crecer

Indica cuánto espacio libre puede ocupar.

.item { flex-grow: 1; }
flex-shrinkHIJO

Puede encogerse

Controla cuánto puede reducirse cuando falta espacio.

.item { flex-shrink: 1; }
flex-basisHIJO

Tamaño base

Establece el tamaño inicial antes de repartir el espacio.

.item { flex-basis: 200px; }
